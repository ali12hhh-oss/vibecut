# VibeCut Pro professional roadmap

This project is intentionally built with free and openly usable building blocks:

- Flutter and Dart for the app shell and editor UI.
- FFmpeg Kit integration already declared by the project for local video processing.
- Bundled offline assets only when their licenses allow redistribution and commercial use.
- Downloadable asset folders for user-provided or license-approved packs.

## Product modules

1. **Projects**: local drafts, autosave, thumbnails, duplicate/delete/export history.
2. **Media import**: device media picker, permissions, validation, FFprobe metadata.
3. **Editor**: preview, multi-track timeline, trim, split, text, stickers, LUT filters, overlays, transitions.
4. **Export**: FFmpeg command builder, progress tracking, presets, save/share.
5. **Assets**: local catalog for free fonts, stickers, overlays, transitions, and LUT packs.
6. **Settings**: language, theme, default aspect ratio, bitrate, FPS, and cache cleanup.

## Licensing policy

Do not add an asset, font, LUT, sound, video overlay, or template unless at least one condition is true:

- It is created by the project owner.
- It is public domain/CC0.
- It has an MIT, Apache-2.0, BSD, OFL, or equivalent permissive license.
- It has written permission for app redistribution and commercial use.

Every new third-party asset pack must include a notice file with source URL, author, license, and allowed usage.
